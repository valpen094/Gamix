# Gamix

Gamix は、Windows 向けのスタイリッシュで高機能なオーディオコントローラー・ボリュームミキサーです。
ゲームや作業、リラックスタイムなど、シーンに合わせて音量設定や出力デバイスを瞬時に切り替えることができます。

## 主な機能

- **高度なボリュームミキサー**: アプリケーションごとの音量を個別に調整できます。
- **デバイス切り替え**: 出力デバイス（スピーカー、ヘッドホン）や入力デバイス（マイク）を簡単操作で切り替え可能です。
- **プリセット機能**: 複数のアプリの音量バランスや使用デバイスを「プリセット」として保存し、ワンクリックで適用できます。
- **テーマ機能**: 気分に合わせて外観を変更可能。「ゲーミング」、「パステル」、「オーシャン」などのテーマを用意しています。
- **システムトレイ常駐**: ウィンドウを閉じてもバックグラウンドで動作し、システムトレイアイコンから素早くアクセスできます。
- **スタートアップ連携**: Windows 起動時に自動で実行する設定が可能です。

## 使い方

### 基本操作
1. アプリを起動すると、現在の各アプリの音量一覧が表示されます。
2. ヘッダーのデバイス名をクリックすると、利用可能なデバイス一覧から切り替えができます。
3. サイドバーからプリセットの保存・適用が可能です。

### バックグラウンド実行
- ウィンドウ右上の「×」ボタンを押すと、アプリは終了せずシステムトレイに格納されます。
- システムトレイのアイコンをクリックするとウィンドウが再表示されます。
- アイコンを右クリックすると、クイックメニュー（プリセット適用、デバイス変更、終了など）にアクセスできます。

### コマンドライン引数
起動時に以下の引数を指定できます。

- `--minimized`: ウィンドウを表示せず、最小化（システムトレイ格納）状態で起動します。スタートアップ登録時に自動的に使用されます。

## 開発者向け情報

### 必要要件
- Windows 10 / 11
- .NET 8.0 SDK

### ビルドと実行

```powershell
# ディレクトリへ移動
cd Gamix

# ビルド＆実行
.\Scripts\build.cmd
```

### プロジェクト構成
- **Gamix.Core**: ビジネスロジック、データモデル、サービスインターフェース
- **Gamix.UI**: WPF によるユーザーインターフェース実装
